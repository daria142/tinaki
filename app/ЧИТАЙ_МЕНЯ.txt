1. Установите Node.js 20 LTS (nodejs.org), если ещё нет.
2. Откройте файл .env.local в блокноте и вставьте ключ anon public из Supabase
   (Project Settings -> API) вместо ВСТАВЬТЕ_СЮДА_ANON_PUBLIC_КЛЮЧ. Без кавычек и пробелов. Сохраните.
3. Дважды щёлкните ЗАПУСК.bat. Подождите, пока появится Ready.
4. Откройте http://localhost:3000
Если окно ЗАПУСК.bat уже открыто со старой версией, закройте его (Ctrl+C) перед новым запуском.
Файл .env.local не загружайте на GitHub. Для публикации см. README.md.
